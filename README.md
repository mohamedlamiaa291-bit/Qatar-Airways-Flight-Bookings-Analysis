# ✈️ Qatar Airways Flight Bookings & Operations Analysis
## 📌 Project Overview
This repository contains a comprehensive data analysis project focusing on **Qatar Airways flight bookings**. The dataset tracks passenger trends, ticket pricing dynamics, travel classes, loyalty tiers, customer satisfaction ratings, and on-time flight operational performance.
---
## 🛠️ Tools & Technologies Used
* **Data Analysis & Processing:** Excel, Power Query, Advanced Functions
* **Version Control & Portfolio:** GitHub
* **Visualization Concepts:** KPI Cards, Interactive Filtering, Trend Analysis
---
## 📊 Dataset & Features Summary
The dataset includes detailed operational and customer metrics:
* **Booking Details:** Booking ID, Booking Date, Booking Channel (Mobile App, Website, Call Center)
* **Passenger Demographics:** Passenger Name, Age, Gender, Loyalty Tier (Gold, Burgundy, Non-member, etc.)
* **Flight Specifications:** Region, Destination, Travel Class, Aircraft Type (e.g., Airbus A350, Boeing 777)
* **Performance & Feedback:** Ticket Price ($), Flight Status, Delay (Mins), On-Time Performance, and Customer Ratings (1-5)
---
## 🚀 Key Insights & Objectives
* Evaluating ticket price variations across different global regions and travel classes.
* Tracking flight delays and on-time performance metrics to measure operational efficiency.
* Analyzing customer loyalty distribution and satisfaction ratings to enhance service quality.
